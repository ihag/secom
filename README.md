# SECOM 반도체 공정 센서 데이터 기반 불량 예측

반도체 제조 공정의 센서 데이터(590개 변수)로 불량 웨이퍼 로트를 예측하는 프로젝트입니다.
데이터 누수를 막기 위해 시간순 분할을 쓰고, 전처리 기준은 train 데이터로만 정했습니다.

> 진행 상태: 전처리 완료 / Baseline 모델 진행 중

## 1. 문제 정의

- **목표**: 센서 측정값으로 불량(1) / 정상(-1)을 예측
- **문제**: 불량이 약 6.6%뿐이라 불균형이 심하고, 변수가 590개로 많으며 결측이 많음
- **평가 관점**: 불량을 놓치는 비용이 더 크다고 보고 Recall과 PR-AUC 중심으로 평가 (TODO: 근거 보강)
- **산업적 맥락**: 수율 분석, FDC(장비 이상 탐지)와 같은 종류의 문제

## 4. 데이터 분할 (누수 방지)

랜덤 분할이 아니라 **시간순**으로 앞 80%를 train, 뒤 20%를 test로 나눴습니다.
실제 공장에서는 과거 데이터로 학습해 미래를 예측하기 때문입니다.

| | 샘플 수 | 불량 개수 | 불량 비율 |
|---|---|---|---|
| train | 1,253 | 87 | 약 6.9% |
| test | 314 | 17 | 약 5.4% |

**주의**: test의 불량이 약 17개뿐이라, 모델이 1~2개만 더 맞혀도 Recall이 크게 움직입니다.
단일 test 점수만으로 모델을 판단하지 않습니다. (TODO: 시간순 교차검증 `TimeSeriesSplit` 적용)
